# ساعت کرنو — فروشگاه آنلاین ساعت

سایت فروشگاهی کامل برای فروش ساعت مچی، کاملاً فارسی (RTL)، فقط HTML / CSS / JS ساده — بدون فریمورک یا فرآیند بیلد، آماده‌ی دیپلوی روی GitHub Pages.

## ساختار پروژه
```
.
├── index.html            صفحه اصلی
├── products.html         لیست محصولات (فیلتر برند/جنسیت/قیمت + مرتب‌سازی)
├── product_detail.html   جزئیات یک محصول (رندر پویا بر اساس ?id=)
├── cart.html             سبد خرید + کد تخفیف
├── checkout.html         تسویه‌حساب (فرم گیرنده + روش پرداخت + تاییدیه سفارش)
├── compare.html          مقایسه حداکثر ۳ محصول کنار هم
└── static/
    ├── css/style.css
    ├── js/main.js        داده محصولات + کل منطق سبد خرید/مقایسه/فیلتر/تسویه‌حساب
    └── img/
```

## دیپلوی روی GitHub Pages
1. محتوای این پوشه رو با همین ساختار (فایل‌های html در ریشه) به یک ریپازیتوری جدید در گیت‌هاب push کنید.
2. Settings → Pages
3. Source: `Deploy from a branch` → برنچ `main` و پوشه‌ی `/ (root)` → Save
4. بعد از چند دقیقه، سایت روی آدرس `https://<username>.github.io/<repo-name>/` در دسترسه.

## نکات مهم
- تمام داده‌ی محصولات (نام، برند، قیمت، مشخصات) داخل `static/js/main.js` در آرایه‌ی `PRODUCTS` تعریف شده؛ برای تغییر یا افزودن محصول واقعی، همون آرایه رو ویرایش کنید.
- تصاویر محصولات فعلاً با گرادیان‌های رنگی CSS (کلاس‌های g1 تا g8) جایگزین شدن. برای استفاده از عکس واقعی، عکس‌ها رو داخل `static/img/` بذارید و در تابع `productCard` و توابع رندر مشابه در `main.js`، به‌جای `div.product-thumb`، تگ `<img>` قرار بدید.
- سبد خرید، مقایسه و کد تخفیف همگی با `localStorage` مرورگر کار می‌کنن (سمت کاربر، بدون سرور)؛ چون GitHub Pages فقط فایل استاتیک سرو می‌کنه، ثبت سفارش واقعی و ارسال ایمیل نیاز به یک بک‌اند یا سرویس‌هایی مثل Formspree داره.
- کد تخفیف نمونه فعال: `KERONO10` (۱۰٪ تخفیف) — داخل تابع `bindCouponForm` در `main.js` قابل تغییر یا اضافه کردن کدهای بیشتره.
